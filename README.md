# MotoPeak — магазин мототехники

**Дисциплина:** Введение в интернет-технологии
**Практическая работа:** № 1 (Страницы сайта: разметка, оформление, навигация)
**Вариант:** 12 (Магазин мототехники)
**Группа варианта:** А (Каталог и подбор)

## Описание проекта
Статический сайт-витрина для магазина мототехники. Включает в себя 5 страниц: Главная, Каталог, Страница товара, Корзина и Контакты.

## Как запустить
1. Скачайте проект.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
3. Дополнительные зависимости не требуются.

## Что уже сделано (ПР1)
- Семантическая разметка HTML5 (header, nav, main, article, section, footer).
- Вынос стилей в отдельный файл `css/style.css`.
- Построение адаптивного макета на Flexbox и CSS Grid.
- Проверка отображения при ширине экрана 360px (мобильные устройства).
- Проверка кода через W3C Validator (ошибок нет).
- Добавлен собственный логотип и favicon.
