# MotoPeak — магазин мототехники

**Учебный проект** по дисциплине «Введение в интернет-технологии».
**Выполненные работы:** Практическая работа № 1 (Верстка) и Практическая работа № 2 (Интерактивность и API).
**Вариант:** 12 (Магазин мототехники, Группа А - Каталог и подбор).

## 📖 Описание проекта
Интерактивный сайт-витрина интернет-магазина мототехники. Проект включает в себя 5 страниц с адаптивным дизайном, семантической разметкой, динамической фильтрацией товаров, валидацией форм и интеграцией с внешним API для конвертации валют.

**Ссылка на опубликованный сайт (GitHub Pages):** 
👉 [https://nikolayssss.github.io/MotoPeak/](https://nikolayssss.github.io/MotoPeak/)

## 🛠️ Используемые технологии
* **HTML5** (семантическая разметка, формы, таблицы, data-атрибуты)
* **CSS3** (Flexbox, CSS Grid, медиа-запросы для адаптивности)
* **JavaScript (ES6+)** (DOM API, Fetch API, асинхронность, обработка ошибок, localStorage)
* **Внешний API:** Курсы валют ЦБ РФ (cbr-xml-daily.ru)
* **Git / GitHub** (контроль версий и хостинг)
